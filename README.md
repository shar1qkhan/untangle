# 🧵 Untangle

A cosy, daily choice puzzle game. Drag the nodes to remove the crossings. No timer, no lives — just turn chaos into order.

## 📱 Play the Game (Android)
You don't need the Google Play Store to play this. 

1. Go to the **[Releases](../../releases)** tab on the right side of this page.
2. Download the latest `app-release.apk` file.
3. Open the file on your Android phone. *(You may need to allow "Install from unknown sources" in your settings).*
4. Play!

## ✨ Features
- **Daily Knot:** A fresh puzzle every morning to build your streak.
- **Infinite Campaign:** Procedurally generated levels that adapt to your skill.
- **Cosy Aesthetics:** Warm beige tones, soft haptics, and satisfying audio.
- **Accessibility:** Colourblind mode, Zen Mode, and wordless gameplay.
- **No Ads on launch:** Just you and the puzzle.

## 🛠️ Built With
- HTML5 / Vanilla JS
- Tailwind CSS
- [Capacitor](https://capacitorjs.com/) (for Android wrapping)
